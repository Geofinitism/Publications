## Core Claim

While Part I established Finite Symbolic Dynamics as a framework for the endogenous dynamics of finite symbolic registrations, Part II changes direction to ask a prior question: how do symbolic streams come into existence in the first place? The central proposal is that scientific development can be read as a history of increasingly refined distinctions — and that the transition at which an interactional event becomes a finite symbolic registration occupies a theoretically critical position. This transition, called the *generonic boundary*, is the point at which the symbolic domain begins. A functional element that performs this Sensing-to-Symbol transformation is provisionally termed a *Transfictor*. The Transfictor is not defined by electronic architecture; it may be implemented through thresholding, detection, categorisation, visual discrimination, assay interpretation, counting, or linguistic stabilisation. Once the generonic boundary has been crossed, the symbolic system itself evolves: new distinctions require new symbols; new symbols enlarge the space of available symbolic trajectories; new trajectories permit new instruments to be conceived. Scientific development is therefore better represented as a coupled loop — language ↔ instrument ↔ measurement — rather than as a one-way pipeline from world to description. This coupled historical model culminates in a tentative interpretation of the large language model as a new type of scientific instrument: one that acts not primarily on light, voltage, mass, time, or spatial extent, but on the symbolic relational field itself, increasing the density of symbolic trajectories accessible to an investigator. Since increased resolution also creates new forms of error, the appropriate response is not rejection but characterisation, calibration, and provenance.

## LLM Error Taxonomy (Chapter 12)

| Instrumental Term | Symbolic Instrument Analogue |
|-------------------|------------------------------|
| gain | amplification of sparse symbolic input |
| bandwidth | range of accessible symbolic domains |
| resolution | fineness of available linguistic distinction |
| noise | irrelevant or unstable continuations |
| distortion | trajectory-changing reformulation |
| drift | progressive movement away from the initial distinction |

**Key error modes**: (1) Symbolic trajectory distortion — T_0 → T_1 → T_2 → T_3 becomes T_0 → T'_1 → T'_2 → T'_3; coherent output does not establish trajectory fidelity. (2) Premature stabilisation — tentative distinction → named concept → formal framework before sufficient measurement; instrument over-resolves the input. (3) Dominant attractor importation — T_novel → T_dominant; novel trajectories pulled toward familiar linguistic basins.

## Provisional Principles of FSD Part II (Chapter 16)

| Principle | Statement |
|-----------|-----------|
| 1. Measurement Produces Finite Distinction | A measurement becomes scientifically available when an interaction is stabilised as a finite symbolic distinction |
| 2. The Generonic Boundary Marks a Change of Representational Status | The passage from sensed interaction to symbolic registration is a foundational transformation and should remain visible in the description |
| 3. A Transfictor Performs Sensing-to-Symbol Transformation | A Transfictor is any functional element that converts a sensed or interactional distinction into a finite symbolic registration |
| 4. An ADC Is a Particular Transfictor | The analogue-to-digital converter provides a clear technological example but does not exhaust the concept |
| 5. Symbolic Translation Is Not New Measurement | Changing a numerical base, representation, matrix arrangement, or linguistic expression does not by itself create a new measurement |
| 6. Scientific Resolution Is the Capacity to Stabilise Reproducible Distinctions | Resolution may be spatial, temporal, spectral, numerical, or symbolic |
| 7. Language Has Resolution | The resolving power of a language depends not only upon vocabulary size but upon combinatorial structure, trajectory availability, historical context, and admissible use |
| 8. New Symbols Create New Trajectories | A new term changes the relational landscape because it participates in many possible symbolic paths |
| 9. Language and Instruments Co-Evolve | New language enables new instruments, and new instruments enable new distinctions that demand further language |
| 10. Increased Resolution Creates New Error Structures | Finer distinction increases both representational possibility and the number of ways boundaries can be misplaced |
| 11. LLMs Are Symbolic Instruments | A large language model can be treated as an instrument acting upon the symbolic relational field and increasing accessible symbolic trajectory density |
| 12. Symbolic Instruments Require Calibration | The errors of symbolic instruments include drift, distortion, premature stabilisation, compression loss, and attraction toward dominant linguistic basins |
| 13. Provenance Is Part of Calibration | A transformation history permits symbolic drift and distortion to be located and assessed |
| 14. The Present Epoch Is Recursively Instrumental | Symbolic instruments can now participate in the conception and design of future physical and computational instruments, closing the historical loop between measurement and language |
